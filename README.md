# ShopWave E-Commerce

## Features

- User Authentication
- Product Search
- Shopping Cart
- Wishlist
- Seller Dashboard
- Admin Dashboard
- Secure Payments (Stripe)
- Responsive Design

## Tech Stack

- React
- TypeScript
- Express.js
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
- PNPM Workspace

## Getting Started

```bash
pnpm install
pnpm dev
```
